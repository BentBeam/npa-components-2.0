# Instruktioner för agenter

Reglerna för det här repot står i [CLAUDE.md](./CLAUDE.md). De gäller alla
AI-verktyg, inte bara Claude Code — läs den filen innan du ändrar något.

Körschemat för att bygga en komponent från Figma ligger i
[.claude/skills/ny-komponent/SKILL.md](./.claude/skills/ny-komponent/SKILL.md).
Följ det steg för steg även om ditt verktyg inte har stöd för skills.

Kortversionen, om du bara läser en sak: **Figma är sanningen, allt går via
tokens, och inget skrivs direkt till `main`.**
